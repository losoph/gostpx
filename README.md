# gostpx

Трей-переключатель системного прокси для macOS и Windows. Один прокси из конфига, один клик — и поддерживаемый трафик системы направляется через него. Простой и прозрачный инструмент без подписок, сложных правил маршрутизации и раздутых конфигураций. Поддерживает три протокола апстрима: SOCKS5, HTTP(S) и SSH.

## Принцип работы

**Что можем перехватить — перехватываем, чего не можем — честно показываем.**

Никаких попыток принудительно дожать сетевой стек: тул не блокирует QUIC, не перехватывает чужой DoH, не внедряется в чужие процессы, не ставит самоподписанные CA-сертификаты и не отключает IPv6 на сетевых интерфейсах. Если трафик проходит мимо прокси, тул честно предупреждает об этом в меню и CLI.

> [!WARNING]
> **Это не средство анонимности.** Kill-switch в проекте отсутствует по архитектурному решению: при обрыве соединения или отключении прокси трафик идёт напрямую к адресату с реальным IP машины. Трей немедленно меняет статус и сообщает об обрыве, но трафик не блокирует. Если сценарий требует абсолютной гарантии отсутствия утечек IP, gostpx для него не подходит.

## Возможности

- **Трей macOS и Windows:** наглядные статусы (🟢 вкл, 🔴 OFF, 🔴 оборвано / ошибка, 🟡 нет сети), измерение RTT, отображение внешнего IP по явному запросу.
- **Окно Настроек:** встроенное графическое окно (Wails v3) с проверкой соединения, управлением параметрами и хирургическим обновлением TOML с сохранением всех комментариев.
- **Проверка соединения рукопожатием:** полноценное рукопожатие с апстримом (SOCKS5/HTTP/SSH) и CONNECT к контрольному узлу, а не просто TCP-подключение; неверный логин или протокол не выглядят как «подключено».
- **Автопереподключение:** автоматическое восстановление сессии при сбоях апстрима (интервалы 5 → 10 → 20 → 40 → 60 с) и распознавание потери локальной сети («нет сети»).
- **Автозапуск:** интеграция с LaunchAgent на macOS и реестром (`HKCU\...\Run`) на Windows (по умолчанию отключён).
- **Уведомления ОС:** нативные системные уведомления об обрыве и восстановлении соединения (macOS).
- **Полнофункциональный CLI:** команды `on`, `off`, `toggle`, `status`, `set`, `test`, `mode`, `config`, `env`.
- **Команда `gostpx env`:** быстрый экспорт переменных окружения (`HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`, `NO_PROXY`) для использования в `eval` текущего шелла (POSIX и PowerShell) консольными программами (`curl`, `git`, `npm`).
- **Безопасное хранение паролей:** пароль хранится в отдельном файле `credentials.toml` с правами доступа `0600` ([ADR-011](docs/DECISIONS.md#adr-011)); файл `config.toml` не содержит секретов и пригоден для совместного использования.
- **Горячая перезагрузка конфига:** изменения подхватываются на лету; ошибка синтаксиса не роняет активную сессию и сохраняет старые рабочие параметры.

## Охват трафика

- **Ловится:** программы, уважающие системный прокси: на macOS — Safari и приложения на CFNetwork (проверено), Chromium-браузеры и Firefox (ожидание); на Windows — Edge, Chrome и потребители WinINET (проверено).
- **Не ловится в режиме `sysproxy`:** консольные утилиты без переменных окружения (для них — `gostpx env`), приложения с собственным сетевым стеком, UDP/QUIC, DNS программ, идущих мимо прокси. Имена в проксируемых соединениях резолвит апстрим, локально gostpx ничего не резолвит.
- **Локальный loopback:** соединения с `127.0.0.1`, `localhost` и `::1` намеренно направляются локально напрямую ([ADR-019](docs/DECISIONS.md#adr-019)), предотвращая разрыв сессий с локальными сервисами и API.

Точный охват каждого режима и результаты замеров описаны в нормативном документе [docs/LIMITATIONS.md](docs/LIMITATIONS.md).

## Установка

Готовые сборки доступны на странице [GitHub Releases](https://github.com/losoph/gostpx/releases):

- **macOS (Universal: Apple Silicon и Intel):** `gostpx-macos-universal.zip`. Распакуйте `gostpx.app` в папку `/Applications`. Приложение собрано с ad-hoc подписью: при первом запуске откройте его через контекстное меню (правый клик → «Открыть») либо снимите карантин в терминале:
  ```bash
  xattr -dr com.apple.quarantine /Applications/gostpx.app
  ```
- **Windows (x64 / arm64):**
  - `gostpxw-windows-amd64.exe` (или `arm64`) — трей-приложение;
  - `gostpx-windows-amd64.exe` (или `arm64`) — консольная утилита (CLI).

## Быстрый старт

```bash
# 1. Задать прокси (пароль автоматически сохранится в credentials.toml)
gostpx set socks5://user:pass@proxy.example.net:1080

# 2. Проверить доступность прокси
gostpx test

# 3. Включить системный прокси
gostpx on

# 4. Проверить статус и внешний IP
gostpx status --check-ip

# 5. Настроить текущий шелл для консольных программ
eval "$(gostpx env)"
```

### Расположение файлов конфигурации

- **macOS:** `~/Library/Application Support/gostpx/config.toml` (и `credentials.toml`)
- **Windows:** `%APPDATA%\gostpx\config.toml` (и `credentials.toml`)

Путь к файлу конфигурации можно узнать командой `gostpx config path`, а открыть в редакторе — `gostpx config edit`.

## Сборка из исходников

Для сборки требуется **Go 1.27**.

```bash
# macOS: трей и CLI — один бинарник (нужен CGO), упаковка в .app с ad-hoc подписью
go build -o work/gostpx ./cmd/gostpx
./build/darwin/package.sh work/gostpx dev work/gostpx.app 0 work/gostpx.zip

# Windows: CLI
GOOS=windows go build -o gostpx.exe ./cmd/gostpx

# Windows: трей (подсистема windowsgui)
GOOS=windows go build -ldflags "-H windowsgui" -o gostpxw.exe ./cmd/gostpxw

# Проверка кода и тесты
go vet ./...
go test -race -tags gostpxtest ./internal/...
```

## Статус проекта

Проект находится на стадии **alpha** (Phase 2): режим `sysproxy` для macOS и Windows с треем и CLI. Linux не поддерживается. Разработка режима `tun` с системным драйвером отложена ([ADR-017](docs/DECISIONS.md#adr-017)).

Чего нет сознательно:
- Kill-switch, списков обхода (bypass), заворачивания IPv6, выбора схемы DNS ([ADR-008](docs/DECISIONS.md#adr-008));
- Нескольких профилей, автоматического переключения при сбоях и балансировки ([ADR-012](docs/DECISIONS.md#adr-012));
- Протоколов Shadowsocks и WireGuard ([ADR-010](docs/DECISIONS.md#adr-010)).
